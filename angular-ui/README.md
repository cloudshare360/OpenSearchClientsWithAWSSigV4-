# Angular UI

Employee Search Frontend Application built with Angular 17+.

## Development

```bash
npm install
npm start
```

Open http://localhost:4200

## Docker

```bash
docker build -t angular-ui .
docker run -p 4200:4200 angular-ui
```

## Features

- Full-text employee search
- Advanced search with filters
- Employee CRUD operations
- Dashboard with statistics
- Responsive Bootstrap UI
